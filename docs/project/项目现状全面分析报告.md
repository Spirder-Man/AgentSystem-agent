## 一、项目整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                    agent1-web (Vue 3 + Vite 5)               │
│               38 页面 .vue | 49 .ts | 27 测试                 │
│              Element Plus + ECharts + Pinia + Vue Router      │
└───────────────────────┬──────────────────────────────────────┘
                        │ HTTP REST + JWT Bearer
┌───────────────────────▼──────────────────────────────────────┐
│                 Agent1.Api (ASP.NET Core 8 Web API)           │
│           15 控制器 | 5 中间件 | Swagger | OpenTelemetry       │
│        JWT (BCrypt) | 限流 | 全局异常 | 请求ID透传             │
└───────────────────────┬──────────────────────────────────────┘
                        │ 项目引用
┌───────────────────────▼──────────────────────────────────────┐
│              Agent1 (Console App / 核心类库 .NET 8)            │
│   ┌──────────┬──────────┬──────────┬──────────┬──────────┐   │
│   │ 12 Module│  7 AI   │ 14 合规  │ 12 知识库│  8 对话  │   │
│   │ 推理模块 │  服务    │  工具    │  服务    │  管理    │   │
│   └──────────┴──────────┴──────────┴──────────┴──────────┘   │
│   124 C# 文件  |  Semantic Kernel 1.74  |  llama.cpp 集成     │
└───────────────────────┬──────────────────────────────────────┘
                        │
┌───────────────────────▼──────────────────────────────────────┐
│           基础设施层 (Linux RTX 3090 24GB)                     │
│  llama-server :8080 (Qwen3-8B)  |  :8081 (nomic-embed)       │
│  bge-reranker :8082 (Python)  |  PostgreSQL :5432 + pgvector  │
└──────────────────────────────────────────────────────────────┘
```

**层次结构特点：**
- **三层分离**：核心类库(Agent1) → Web API(Agent1.Api) → 前端SPA(agent1-web)，共享项目引用而非重复代码
- **双通道解耦**：事实通道（C# 确定性代码，法规引用100%准确）∥ 解释通道（LLM推理+建议），四道防线防幻觉
- **控制台+Web双入口**：`Agent1/Program.cs`（20菜单CLI）∥ `Agent1.Api/Program.cs`（REST API），共享全部业务逻辑
