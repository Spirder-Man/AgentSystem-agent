## 第 0 步：先立 B

**储存禁忌规则引擎**，回答"苯怎么存"时给出禁忌警告。两张表分工：
- `chemical_incompatible_categories`（类别级，193 行）：物质 → 文本描述的禁忌对象（"氧化剂""强酸"等）
- `chemical_incompatibilities`（精确配对，21 行）：A ↔ B 精确配对 + 原因 + 法规依据

**查询链路**（ChemicalKnowledgeGraph.CheckCompatibility，L309-361）：
1. 精确边优先：`_incompatEdges[(aId,bId)]` + 反向 `[(bId,aId)]`（L323-324）——**代码层双向查找，数据库只需存单方向**
2. 类别级判定：`a.IncompatibleWith` 与 `b.HazardCategories` 互相 contains 匹配（L328-344）
3. 同类兼容推断：类别重叠 → 返回"可同库分区存放"（L346-358）

## 第 3 步：三层考古（落差分析）

### ⚠️ 落差 1（P1，#25）：硝酸→盐酸 标"兼容"——实际是王水！

```
硝酸 → 盐酸  is_compatible = TRUE
Reason: "两种强酸可同库分区存放，但需注意硝酸为氧化性需防腐蚀隔离"
```

**化学事实**：硝酸+盐酸 = **王水（aqua regia）**——混合瞬间放热、产生氯气和亚硝酰氯剧毒气体，可溶解金铂。GB 15603 配存表：硝酸（氧化剂类）与盐酸为**禁配**。

**影响**：用户问"硝酸和盐酸能一起存吗" → 系统回答"可以同库" → **直接给出错误的安全建议**（全库唯一"答错要出事故"的表，这里答错了）。

**修复**：改为 is_compatible=false，reason 填王水反应说明，补 regulation_ref。

### ⚠️ 落差 2（P2，#26）：硫化氢→二氧化硫 标"兼容"——克劳斯反应

```
硫化氢 → 二氧化硫  is_compatible = TRUE
Reason: "同属酸性气体(还原性)，可同库但需有效隔离和通风"
```

**化学事实**：2H₂S + SO₂ → 3S + 2H₂O（克劳斯工艺核心反应，放热，产物硫沉积）。两者相遇存在反应性，且 H₂S 为易燃有毒气体。配存表倾向隔离储存。

**修复**：待专家复核；至少不应标"可同库分区存放"这么轻。

### ⚠️ 落差 3（P2，#27）：82% 类别规则是"死规则"

**验证**（L0 交叉实测）：hazard_categories 的 category 是 **GHS 术语全集**（20 种：氧化性固体/液体/气体、易燃液体、金属腐蚀物等），而 incompatible_with 是**通俗词/具体物质名**。

`CheckCompatibility` L332-333 的匹配逻辑：`hc.Category.Contains(incat) || incat.Contains(hc.Category)`

| 匹配结果 | incompatible_with 数 | 对应规则条数 |
|---------|---------------------|-------------|
| 可触发（氧化剂/易燃液体/易燃固体/金属/氧 等 ~5 词） | 5 个 | ~35 条 |
| **死规则（硝酸/氨/高锰酸钾/过氧化氢/氯化氢/氢氧化钠…66 词）** | **66 个** | **~158 条（82%）** |

**例**："硝酸"禁忌 10 条（10 种物质写"禁忌硝酸"）——contains 匹配要求 HazardCategories.Category 含"硝酸"字样，实际 category 是"氧化性液体" → **永不触发**。用户问"高锰酸钾和硝酸能一起存吗"，若精确表无此边，类别级判定**漏判**。

**根因**：种子数据两套词汇表（通俗词 vs GHS 术语）未对齐；无单元测试覆盖类别级判定路径。

### 落差 4（P3，#28）：regulation_ref 空 10/21（47.6%）

一半精确规则无法规依据（对照 knowledge_chunks 溯源 0% #11——全库法规溯源通病）。

### 落差 5（P3，#29）：苯↔丙酮双向冗余 + 无 UNIQUE(a,b)

种子双写对称对（21 行里唯一一对）；无 UNIQUE(a,b) 约束兜底——运行时若双向写入会重复。

### 落差 6（P3，#30）：categories 文本规范 + 裸表

71 种文本同义不同写；无 UNIQUE(substance_id, incompatible_with)（同物质同禁忌可重复）；无查询索引（substance_id 无 idx，删除/联查全表扫）。

---

## 第 4 步：一句话总结

> **禁忌矩阵是"数据质量高、规则正确性差"的表：21 条精确规则的 reason 全部专业（三氯化氮/爆炸极限/王水级细节），但藏着 2 条业务级错误规则（硝酸→盐酸=王水 P1、硫化氢→二氧化硫=克劳斯 P2），且 193 条类别规则中 82% 因词汇表错位成为死规则——安全底座需要专家复核 + 词汇表对齐 + UNIQUE(a,b) 约束。**

## 精读 SQL 速用卡

```sql
-- ── 反向重复（A->B 与 B->A 双写）──
SELECT sa.name, sb.name FROM chemical_incompatibilities i
JOIN chemical_incompatibilities r ON r.substance_a_id = i.substance_b_id AND r.substance_b_id = i.substance_a_id
JOIN chemical_substances sa ON sa.id = i.substance_a_id
JOIN chemical_substances sb ON sb.id = i.substance_b_id
WHERE i.id < r.id;

-- ── 死规则验证（incompatible_with 与 GHS 术语匹配度）──
WITH cats AS (SELECT DISTINCT category FROM chemical_hazard_categories)
SELECT t.incompatible_with, count(*) AS 使用次数
FROM (SELECT ic.incompatible_with FROM chemical_incompatible_categories ic GROUP BY ic.incompatible_with) t
WHERE NOT EXISTS (SELECT 1 FROM cats c WHERE c.category LIKE '%'||t.incompatible_with||'%' OR t.incompatible_with LIKE '%'||c.category||'%')
GROUP BY t.incompatible_with ORDER BY 使用次数 DESC;

-- ── 无 regulation_ref 的规则 ──
SELECT sa.name, sb.name FROM chemical_incompatibilities i
JOIN chemical_substances sa ON sa.id = i.substance_a_id
JOIN chemical_substances sb ON sb.id = i.substance_b_id
WHERE i.regulation_ref IS NULL OR i.regulation_ref = '';
```
