关键设计决策 为什么这么写
Lazy<T> — LlmService ↔ HybridKBService 互锁，延迟解析破循环
FunctionChoiceBehavior.Required() — 强制 LLM 调工具，但有框架Bug
BM25+Vector RRF 融合 — 关键词精度 + 语义召回的工程折中
GPU向量=全量加载+暴力余弦 — 简单可靠，牺牲延迟换可维护性
硬编码字典兜底 — RAG 失败时的最后防线（评测中多次触发）
语义重复检测 v2 — "是否合规"计数≥5截断，替代严格行匹配
