▌"一箭双雕"测试路径（菜单8一个入口覆盖最多层）

选择菜单 8（化工合规自查）→ 输入 "苯和丙酮可以同库储存吗？" 这一条命令同时触发: ├─ Layer 1: SafetyGuardService.ValidateInput("苯和丙酮...") → safe=true ├─ Layer 1: IntentRouter.Route("苯和丙酮...") → 命中"储存"关键词 ├─ Layer 1: SafetyGuardService.ValidateOutput(response) → 检查高危断言 ├─ Layer 2: AgentDialog.ExecuteAsync → 完整6步流水线 │ ├─ PipelineMetrics 16字段采集 │ └─ PipelineEvent 9事件链条 ├─ Layer 3: HybridKnowledgeBaseService.SearchAsync → RAG检索 ├─ Layer 4: ChemicalComplianceTools.CheckStorageCompatibility → 工具调用 ├─ Layer 5: (如果走巡检) InspectionOrchestrator → 规则引擎+编排 └─ Audit: AuditService.LogOperationAsync → 审计记录 验证清单: □ 输出含 [REGULATIONS: GB 15603-1995] □ 输出含 [判定:is_compliant=false] □ 没有 "可以同库" 被拦截的警告（若有则说明SafetyGuard生效） □ PipelineMetrics 显示 TotalMs>0 □ 日志文件 grep "TraceId=" 可串起全链路
