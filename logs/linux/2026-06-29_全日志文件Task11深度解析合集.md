#### 维度 1：日志格式解析

**单次嵌入任务生命周期 (6 步循环)**：

```
1. slot get_availabl   → 选择最佳 slot (LCP 相似度匹配)
2. slot launch_slot_   → 开始处理 task N
3. slot process_sing ×3 → 保存/清空其他 idle slots 的 prompt cache
4. slot prompt_clear ×3 → 清空其他 slots
5. slot release        → n_tokens = 4, 释放 slot
6. srv update_slots    → all slots are idle → 回到步骤 1
```

| 字段 | 值 | 含义 |
|---|---|---|
| `LCP similarity, sim_best = 1.000` | 100% 前缀匹配 | 所有 22 次请求前缀完全相同 → 每次都命中 prompt cache |
| `n_tokens = 4` | 每次 4 tokens | 嵌入请求很短 (如 "苯的危险类别") |
| `truncated = 0` | 无截断 | 所有 token 都被处理 |
| `task 0, 2, 4, ... 44` | 22 次请求 | 偶数 task ID，可能是 one-way embedding |

#### 维度 2：业务逻辑映射

- **调用方**：Agent1 的知识库初始化 (`HybridKnowledgeBaseService.InitializeAsync()`)
- **场景**：系统启动后对知识库文档进行嵌入索引构建，22 次嵌入请求对应 22 个文档分块
- **LCP=1.000 含义**：每次嵌入请求的 system prompt 完全相同 → llama.cpp 复用缓存的前缀 → 跳过重复计算

#### 维度 4：设计意图说明

- **为什么每次 task 后保存/清空其他 idle slots**：prompt cache 管理策略。活跃 slot 保留缓存，非活跃 slot 清理释放显存 → 确保下次请求有足够空间
- **为什么 LCP slot 选择而非随机**：LCP (Longest Common Prefix) 匹配确保每次请求使用缓存最多的 slot → 最大化推理速度
- **为什么单 slot 工作**：22 次嵌入请求顺序到达，无并发需求 → 仅 slot 3 工作，其他 3 个 slot 空闲但可随时接管

| 字段 | 值 | 含义 |
|---|---|---|
| 失败时间 | `00:00:00.69` | 第 0.69 秒即失败 (排在测试序列前面) |
| 断言 | `.Contain("100.0%")` | 期望不含空格 |
| 实际输出 | `100.0 %` | **C# P1 格式符自动插入空格** |

#### 维度 2：业务逻辑映射

- **代码位置**：[AiInferenceTests.cs:189](../../Agent1.Tests/AiInferenceTests.cs#L189) — 测试断言
- **被测代码**：[ReflectionVerifier.cs:47](../../Agent1/Services/AI/ReflectionVerifier.cs#L47) — 生成 Markdown 报告
- **Bug 根因**：

```csharp
// Bug 代码 (ReflectionVerifier.cs:47):
sb.AppendLine($"📊 事实精度: {c}/{total} ({FactualPrecision:P1})");
// P1 格式符输出 "100.0 %" (空格分隔)

// 修复方案:
sb.AppendLine($"📊 事实精度: {c}/{total} ({FactualPrecision*100:F1}%)");
// F1 格式符输出 "100.0%" (无空格)
```

#### 维度 4：设计意图说明

- `P` 格式符是 C# 标准库行为：在不同 Culture 下数字和 `%` 之间可能有空格
- 测试断言使用精确字符串匹配 → 空格导致 FAIL
- **这是代码 Bug，不是测试 Bug**：生产环境也会输出 `100.0 %`

#### 维度 5：异常信号识别

| 分类 | 判断 |

- **为什么 WebApplicationFactory 抛出 InvalidOperationException**：ASP.NET Core 的 `HostFactoryResolver` 检测到进程退出但无 IHost → 认为启动失败
